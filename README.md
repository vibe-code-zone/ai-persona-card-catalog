# AI Persona Card Catalog

![AI Persona Card Catalog](https://github.com/vibe-code-zone/ai-persona-card-catalog/blob/7cc81d4d946ca85fe0dd01680f06ccbff37de748/images/ai-persona-card-catalog-001.jpeg)

A Terminal User Interface (TUI) application for browsing and applying AI Personas to your projects built with [Textual](https://textual.textualize.io/)

## Basic Usage from Source

```
python3 -m venv ~/.venv-tui
source ~/.venv-tui/bin/activate
pip install -r requirements.txt
python3 ai_persona_card_catalog.py
```
