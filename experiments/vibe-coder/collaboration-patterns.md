# Human-AI Collaboration Patterns

Effective patterns for collaborative development between human and AI partners.

## Communication Patterns
- Explicit approval for git operations and file changes
- Continuous prompt logging for session continuity
- "Mood misalignment" identification and resolution
- Real-time feedback on implementation approaches

## Development Workflow
- User provides requirements and tests functionality
- AI implements features with immediate iteration
- Collaborative debugging of technical issues
- Joint architecture decisions and trade-offs

## Quality Assurance
- User testing with immediate feedback
- Code review through collaborative discussion
- Git attribution for both human and AI contributions
- Documentation of development decisions and rationale
