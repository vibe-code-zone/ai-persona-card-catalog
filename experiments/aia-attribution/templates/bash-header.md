# Bash/Shell Script Attribution Header

## Template for shell scripts

```bash
#!/bin/bash
# AI-generated script following AIA attribution standards
# Reference: https://aiattribution.github.io/interpret-attribution  
# AIA Code: [AIA_CODE_HERE]
# Model: [MODEL_NAME_HERE]
# Generated: [GENERATION_TYPE_HERE]
# Human Role: [HUMAN_ROLE_HERE]
# Reviewed: [REVIEW_STATUS_HERE]
```

## Usage

Add this header after the shebang line in shell scripts containing AI-generated code.

## Template Variables

- `AIA_CODE_HERE` - AIA standard code (e.g., "PAI Nc Hin R Claude Code v1.0")
- `MODEL_NAME_HERE` - AI model used for generation
- `GENERATION_TYPE_HERE` - What was generated (script logic, automation, etc.)
- `HUMAN_ROLE_HERE` - Human involvement (initiated, reviewed, modified)
- `REVIEW_STATUS_HERE` - Review and approval status
